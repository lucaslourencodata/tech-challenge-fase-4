# O que falta para a entrega (mínimo necessário)

1. **Inicie o Windows:** descompacte a pasta do projeto e abra `INICIAR_WINDOWS.bat`. Se solicitado, instale Python 3.11/3.12.
2. **Gere as respostas:** no painel Streamlit, informe uma chave Gemini ou tenha Ollama funcionando; teste as perguntas sugeridas.
3. **Publique no GitHub:** crie um repositório público e envie o conteúdo da pasta `voc_olist_fase4/`. NÃO envie `.env`, `data/raw/`, `artifacts/` ou `.venv/`.
4. **Grave o vídeo:** siga literalmente `docs/ROTEIRO_VIDEO.md`, mostrando o aplicativo rodando e as evidências. Tempo máximo 7 minutos.
5. **Entregue na plataforma da FIAP:** link do GitHub e arquivo/link do vídeo conforme a orientação do ambiente da disciplina.
